# Runelift — coquille Android

Cette branche contient seulement l'emballage Android (Capacitor) de Runelift.
L'appli elle-même vit sur la branche `main` et est chargée depuis le site.

GitHub compile l'APK à chaque changement sur cette branche (onglet Actions),
et le publie dans les « Releases » sous l'étiquette `android-test`.
